# Midi-Keypad-V2
Woah, it's the Midi Keypad (https://github.com/KaiPereira/MIDI-Keypad) but instead with 3 EC11 rotary encoders and 7 capacitive keys to reduce costs and make some sound!

So, I made this project for week 3 of Half Life by Hack Club and with it being the "DESIGN YOUR INSTRUMENT" week I followed the starter project guide "MIDI Keypad" and modified it to make it mine.
